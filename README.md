# TapTap - タップタップ（Pyxel）

シンプルなタップ連打ゲーム（子ども向け）。単一ファイル実装です。

## 必要条件
- Python 3.11 推奨
- Pyxel

## インストール
```bash
pip install -r requirements.txt
```

## 実行
```bash
python main.py
```

## 操作方法
- マウス/タップで画面をタップするとスコアが上がります。
- スペースキーはデスクトップでのテスト用に中央タップとして機能します。

## 注意
- 外部通信・広告・課金は一切入れていません。
- Pyxel は主にデスクトップ向けです。モバイル端末でのネイティブ動作は環境によります。ブラウザで遊ばせたい場合は別途 p5.js 等へ移植する案があります。
